# SafeShot 安全截图助手（零依赖版）

[English](README.en.md) · [隐私政策 / Privacy Policy](https://xuhongwang.github.io/safeshot/privacy.html)

一款保护隐私的浏览器截图扩展。在页面上可视化框选/自动识别敏感信息，打码后截图，**优先复制到剪贴板**（复制失败自动降级为下载），敏感内容不落盘。

**零依赖**：不依赖任何外部库、CDN 或网络请求，所有代码本地运行。

---

## ✨ 功能特性

- **三种启动方式**：工具栏按钮、右键菜单、快捷键（默认 `Alt+Shift+S`，可在设置页自定义）
- **可视化打码 overlay**：在页面上直接看到遮罩效果，拖拽框选补码、点击已有遮罩删除
- **自动扫描**：可识别密码框、API Key、JWT、手机号、邮箱、内网 IP、数据库连接串、私钥等
- **遮罩样式**：马赛克（可调块大小）或纯色（可选颜色），合成在最终截图上
- **直接复制到剪贴板**：确认即复制，HTTPS / HTTP 页面均支持；复制失败自动降级为下载 PNG
- **overlay 快捷键**：`Enter` 确认截图，`Esc` 取消
- **自定义正则规则**：自行添加敏感信息识别规则
- **域名白名单**：白名单内网站跳过扫描直接截图
- **自动扫描开关**：关闭后仍可截图和手动打码，仅跳过自动识别
- **原始分辨率导出**：截图按页面原始分辨率生成，非预览缩略图
- **中英文双语**：界面、提示与错误信息中英切换，默认跟随浏览器语言，可在设置页手动指定

## 🚀 安装方式（Chrome / Edge）

1. 下载并解压本项目到本地文件夹
2. 打开扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 右上角开启「**开发者模式**」
4. 点击「**加载已解压的扩展程序**」，选择 `safeshot` 文件夹
5. 工具栏出现剪刀图标即可使用

## 📖 使用说明

### 打码截图

1. 打开需要截图的网页
2. 点击工具栏 SafeShot 图标 → 「📷 打码截图」（或右键菜单 / 按 `Alt+Shift+S`）
3. 页面进入遮罩 overlay：自动扫描命中的区域已覆盖遮罩
4. 拖拽添加额外遮罩，点击遮罩删除
5. 按 `Enter` 或点击「确认截图」→ 截图复制到剪贴板；按 `Esc` 或「取消」放弃
6. 结果通过页面 toast 提示；若剪贴板不可用则自动下载 PNG

### 设置

点击扩展图标 → 「⚙️ 设置」：

- **启用自动扫描**：开启时截图前自动识别敏感信息并打码；关闭后仍可截图和手动打码
- **界面语言**：自动（跟随浏览器）/ 中文 / English，切换后界面与提示立即生效
- **域名白名单**：添加后该域名截图跳过扫描直接复制
- **遮罩样式**：马赛克（块大小 4–32px）/ 纯色（自选颜色）
- **自定义正则规则**：添加正则表达式识别特定敏感信息
- **快捷键**：显示当前键位，点「修改」跳转 Chrome 快捷键设置页自定义（`chrome://extensions/shortcuts`）

### 结果反馈

页面底部 toast 显示结果：

- `已复制到剪贴板` / `Copied to clipboard` — 成功
- `已下载截图〔mode=...〕` / `Screenshot downloaded [mode=...]` — 剪贴板失败已降级下载，括号内为诊断信息（链路与错误原因）
- 受限页面（`chrome://` 等）无法注入页面 toast 时，扩展图标显示红色 `!` 徽标，悬停可见错误原因

## 🔒 隐私说明

- 所有检测、打码合成均在本地完成
- 无任何外部请求、无数据上传
- 原始截图仅在处理流程中短暂驻留内存，处理完成后立即释放；下载兜底仅在复制失败时触发

---

## ⚠️ 已知限制

- 无法在浏览器内置页面（`chrome://`、`edge://`）截图
- 跨域 iframe、Canvas 渲染文字、系统级弹窗无法扫描
- 无头浏览器/非聚焦窗口下剪贴板可能不可用（会自动降级为下载）
- 快捷键键位无法在扩展内输入修改（Chrome API 限制），需跳转浏览器快捷键设置页

## 📁 项目结构

```
safeshot-lite/
├── manifest.json       # 扩展配置（Manifest V3）：权限、快捷键、资源声明
├── i18n.js             # 中英双语字典 + 语言解析，供所有上下文共享
├── background.js       # 后台：流程编排、截图、剪贴板/下载兜底、消息处理
├── content-scan.js     # 页面扫描、遮罩 overlay、图片合成、复制链路
├── main-world.js       # MAIN world：HTTPS 页面 navigator.clipboard 写入
├── clip.html / clip.js # HTTP 页面扩展 iframe 剪贴板兜底
├── offscreen.html/js   # offscreen 剪贴板兜底
├── rules.js            # 敏感信息规则库
├── popup.html/css/js   # 弹窗：状态、设置（扫描/白名单/遮罩样式/语言/快捷键）
├── _locales/           # manifest 文案（zh_CN、en），跟随浏览器界面语言
└── icons/              # 扩展图标（16/48/128）
```

### 语言选择

界面语言按以下顺序解析：

1. 扩展内设置（**设置 → 界面语言**）：自动 / 中文 / English
2. 设为「自动」时，取浏览器界面语言（`chrome.i18n.getUILanguage()`）：`zh*` → 中文，其余 → English

`chrome://extensions` 上显示的扩展名称与描述由 Chrome 通过 `_locales` 单独本地化，始终跟随浏览器界面语言。
